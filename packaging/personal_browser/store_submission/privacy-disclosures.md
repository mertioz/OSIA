# Personal Browser privacy disclosure matrix

This matrix describes the delivered extension and local OSIA Personal Browser path. “Transmitted locally” means the extension sends data to the same-user OSIA Desktop Native Messaging host; it does not mean that the extension opens a network connection. If the user selected a cloud AI provider in OSIA, OSIA Desktop may include the observations needed for the requested turn in that provider's model context. If the user selected a local model, that model processing can remain on the PC. This provider distinction must remain visible in the store disclosure and OSIA privacy policy.

Distribution status on 2026-08-18: the extension is unpublished, Chrome Web Store and Microsoft Edge Add-ons preparation is paused, `chrome_store_id` and `edge_store_id` remain empty, and no store submission or visibility change is authorized by this document.

## Dashboard disclosure recommendation

Do not select “no user data handling.” The extension handles user data even when processing is local. At minimum disclose website content/resources, form data or user-provided content when applicable, and current-tab browsing activity (origin/path/title). Authentication and financial/payment data are not collected because those fields and surfaces are blocked. If a dashboard category is broader than this matrix, choose the truthful broader category and use the listing/privacy text to explain the narrow, explicit-tab scope.

The extension's use is limited to its disclosed single purpose. Data is not used or transferred for personalized advertising, credit decisions, data brokerage, unrelated profiling, or sale, and human access is not provided except where separately requested for support/security or required by law under the OSIA privacy policy.
